# Client Finder Web Client

This directory contains the React, TypeScript, and Vite frontend for Client Finder. For the complete project overview, setup instructions, API documentation, discovery flow, and provider limitations, see the [project README](../README.md).

Run the full application from the repository root with:

```powershell
npm run dev
```

Build the client from the repository root with:

```powershell
npm run build
```
